# 추출 알고리즘

## 기간과 입력

`analyze_posts(posts, now, config)`의 기간 경계는 다음과 같습니다.

```text
recent_start     = now - window_hours
background_start = recent_start - background_days

최근: recent_start < reg_date <= now
배경: background_start < reg_date <= recent_start
```

경계에 있는 게시물은 한 구간에만 속합니다. 미래 게시물과 배경 시작 이전의 게시물은 제외합니다. 잘못된 날짜나 시간대 오프셋은 조용히 현재 시각으로 대체하지 않고 오류로 반환합니다.

`trending_keywords(recent_posts, background_posts, now, config)`는 호출자가 이미 두 구간을 나눈 경우에 사용합니다. 이 함수는 날짜로 구간을 다시 나누지 않으며, 배경 게시물에는 제목만 필요합니다.

## 토큰과 후보

Kiwi를 한 작업 스레드로 실행합니다. 최근 제목을 먼저 분석해 `NNP`로 인식된 세 글자 한글 고유 명사가 `min_name_count`번 이상 나오면 사용자 사전에 추가합니다. 이 분석기로 최근·배경 제목을 모두 분석합니다.

남기는 품사는 `NNG`, `NNP`, `SL`, `SH`입니다. 외국어는 소문자로 바꾸고, 두 글자 미만·불용어·숫자만 있는 토큰·자음만 있는 토큰을 제외합니다. 숫자와 짧은 영문, 숫자와 명사가 분리된 일부 표기는 합칩니다. 조사와 다른 품사를 제거한 토큰열에서 1~3-gram을 만들므로 원문의 연속 문자열과 결과가 다를 수 있습니다.

후보 하나의 게시물 내 반복은 한 번만 셉니다. 서로 다른 게시물의 중복은 제거하지 않습니다.

## 게시물 가중치

최근 구간에서 커뮤니티별 조회수 중앙값을 구합니다. 해당 커뮤니티의 게시물이 5개 미만이면 전체 최근 게시물의 중앙값을 사용합니다. 짝수 개 표본의 중앙값은 가운데 두 값의 평균입니다.

```text
view_factor = min(log(1 + views) / log(1 + max(median, 1)), 3)
recency     = 2 ^ (-age_hours / half_life_hours)
weight      = view_factor × recency
```

기본 반감기는 8시간입니다. 8시간 전 게시물은 같은 조회수의 현재 게시물 대비 절반, 16시간 전 게시물은 1/4만 기여합니다. 조회수 0은 가중치 0입니다. 유효하지 않은 조회수도 0으로 처리합니다. 최근 전체 가중치가 0이면 결과는 빈 리스트입니다.

## 배경 대비 증가

```text
N_recent = 최근 게시물 weight의 합
y        = 후보가 등장한 최근 게시물 weight의 합
df_bg    = 후보가 등장한 배경 게시물 수
N_bg     = 배경 게시물 수
a        = prior_count (기본 1)

p_bg   = (df_bg + a) / (N_bg + a)
lambda = N_recent × p_bg
lift   = y / lambda
excess = y - lambda
z      = excess / sqrt(lambda)
```

`z >= min_z`, `lift >= min_lift`, `excess > 0`을 모두 만족해야 합니다. 최근·배경 구간 중 하나라도 비어 있으면 결과를 반환하지 않습니다.

포아송 기대량에서 착안했지만 관측량이 정수 횟수가 아닌 가중치 합입니다. `z`를 p-value, 정확도, 신뢰도 또는 정식 유의성 검정으로 해석하지 않습니다. 특히 수집 대상이나 수집량의 변화는 결과를 크게 바꿀 수 있습니다.

## 구 결합도

최근 구간에서 후보의 문서 빈도를 `p_joint`, 각 구성 토큰의 문서 빈도를 `p_i`로 환산합니다. 2~3-gram의 결합도는 다음과 같습니다.

```text
npmi = (log(p_joint) - sum(log(p_i))) / (-(n - 1) × log(p_joint))
```

2-gram은 일반적인 NPMI이고, 3-gram에는 `n - 1` 정규화를 적용해 완전한 동시 출현이 1이 되도록 합니다. 후보가 모든 최근 문서에 등장하면 분모가 0이므로 0을 반환합니다. 단일 토큰에는 1을 부여하며 결합도 필터를 적용하지 않습니다.

## 커뮤니티 조건과 순위

최소 `min_posts`개 게시물에 등장해야 하고, `min_communities`개 이상의 커뮤니티에서 각각 `min_posts_per_community`번 이상 등장해야 합니다. 이 횟수들은 가중치를 적용하기 전의 문서 수입니다.

커뮤니티별 등장 비율을 `q_i`, 해당 후보가 등장한 커뮤니티 수를 `k`라 하면:

```text
balance = -sum(q_i × log(q_i)) / log(k)
score   = excess × log(lift) × (0.4 + 0.6 × balance)
```

단일 커뮤니티를 명시적으로 허용한 설정에서는 `balance=1`로 둡니다. 점수 내림차순, 최근 등장 게시물 수 내림차순, 키워드 문자열 순으로 정렬합니다.

마지막으로 긴 키워드가 짧은 키워드를 연속 토큰으로 포함하고 점수 비율이 0.6 이상, 등장 게시물 겹침이 0.6 이상이면 짧은 후보를 제거합니다. 이후 상위 `top_n`개에 순위를 부여합니다.

## 해석 범위

샘플은 원본 제목을 주제 용어로 축약한 데이터입니다. 샘플의 순위는 실행 재현용이며 알고리즘 품질을 평가한 벤치마크가 아닙니다. 정확도·재현율·처리 속도에 대한 정량 평가는 아직 수행하지 않았습니다.
