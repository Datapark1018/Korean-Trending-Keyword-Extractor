# DB 기반 샘플 데이터

이 디렉터리는 SQLite 원본에서 **주제 용어만 추출한 파생 샘플**을 제공합니다. 무작위 문장을 만든 합성 데이터는 아니며, 원문 게시물 아카이브도 아닙니다.

| 항목 | 값 |
| --- | --- |
| 분석 기준 | `2026-11-09 23:52:00` (원본 DB와 동일한 시간대 기준) |
| 최근 구간 | 기준 시각 직전 16시간, 131건 |
| 배경 구간 | 최근 구간 직전 14일, 637건 |
| 원본 조회 구간 행 수 | 18,650건 |
| 배포 샘플 | 768건, 3개 가명 커뮤니티 |
| 최초·최종 샘플 시각 | `2026-10-26 14:20:02` / `2026-11-09 23:51:00` |

## 파일

- `sample_posts.jsonl`: 분석에 바로 사용할 수 있는 게시물 목록
- `sample_metadata.json`: 기준 시각, 변환 방식, 구간별 수량, SHA-256
- `sample_vocabulary.json`: 샘플에 남기는 스포츠·e스포츠 용어 목록

## 생성 방식

1. 제공된 DB의 마지막 게시물 시각을 기준으로 최근 16시간과 배경 14일을 조회했습니다.
2. 원문 제목에서 허용 목록의 용어를 긴 문자열 우선으로 찾아 원래 등장 순서대로 남겼습니다. 같은 용어는 제목당 한 번, 최대 12개까지 남깁니다.
3. 용어가 2개 이상이며 팀·대회·선수 등 `anchors`에 해당하는 용어가 최소 1개 있는 게시물만 선택했습니다.
4. 조회수와 시각은 그대로 두었습니다. 원본 ID는 `sample_00001` 형태로, 커뮤니티 이름은 `community_1` 형태로 대체했습니다. 대응표는 저장하지 않았습니다.
5. URL, 본문, 작성자 정보, 원문 제목 필드, 로컬 경로는 배포 파일에 포함하지 않았습니다.

별도 무작위 샘플링은 하지 않았습니다. 데이터의 내용이나 시각을 사실 검증하지 않았으며, 인물·팀 이름의 등장 자체가 해당 사건의 사실성을 의미하지 않습니다. 제목 축약과 주제 선별로 원래의 토큰 결합도·주제 분포가 바뀌므로 정확도 평가, 대중 관심도 추정, 성능 벤치마크에는 적합하지 않습니다.

## 재생성

프로젝트를 설치하고 저장소 루트에서 실행합니다. 원본 DB는 배포하지 않으므로 포함된 파일만으로 원본 조회 과정을 재현할 수는 없습니다. 데모 분석은 원본 DB 없이 실행할 수 있습니다.

```bash
python scripts/build_sample.py --db local/source.sqlite3 --at "2026-11-09 23:52:00"
```

출력은 기본적으로 이 디렉터리의 JSONL·메타데이터를 교체합니다. 별도 검토가 필요하면 `--output-dir local/sample-preview`를 지정하세요. 원본은 읽기 전용으로 접근합니다. 같은 원본 스냅샷·시각·용어 목록에서는 같은 UTF-8/LF 데이터와 해시가 생성됩니다.

## 이용 범위

코드와 변환 스크립트는 저장소의 MIT 라이선스를 따릅니다. 이 샘플은 원문 표현 대신 선별된 주제 용어와 수치 정보를 담습니다. 원본 게시물이나 제3자의 콘텐츠에 대한 권리를 새로 부여하는 것은 아닙니다. 원본 제목·본문·링크를 추가하는 경우에는 해당 자료의 이용 조건을 별도로 확인해야 합니다.
